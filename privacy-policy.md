# Política de Privacidad - Mis Gastos

Última actualización: 2026-08-06

## 1. Introducción
Mis Gastos es una aplicación para controlar gastos y tarjetas. Esta política explica qué datos recopilamos, cómo los usamos y con quién los compartimos.

## 2. Datos que recopilamos
- Datos de autenticación proporcionados por Supabase (correo electrónico).
- Datos de gastos: descripción, monto, categoría, fecha.
- Datos de tarjetas: nombre, últimos 4 dígitos, tipo de tarjeta.
- Datos técnicos: uso de la app, errores, IP y dispositivo para mejorar la experiencia.

## 3. Uso de los datos
Utilizamos los datos para:
- autenticar al usuario
- mostrar historial de gastos y tarjetas
- sincronizar la app con Supabase
- mejorar la seguridad y el rendimiento

## 4. Compartición de datos
No compartimos datos personales con terceros, excepto cuando:
- es requerido por la ley
- es necesario para proteger derechos o la seguridad

## 5. Seguridad
Guardamos datos con Supabase y usamos medidas de seguridad estándar para protegerlos.

## 6. Derechos del usuario
Podés solicitar:
- acceso a tus datos
- rectificación
- eliminación
- portabilidad
